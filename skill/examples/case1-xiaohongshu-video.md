# 测试案例 1：文字转小红书视频

**输入：** 我想要一个能自动把文字转成小红书视频的智能体。

## 期望的需求拆解（用于检查第 1 步）

- 核心功能：把一段文字自动做成适合小红书发布的短视频
- 需求类型：内容生成（加查 C 新品发布、G 社区口碑）
- 子功能：
  1. 文案改写为口播稿 / 小红书风格文案
  2. 按段落生成分镜与配图（或匹配素材）
  3. AI 配音
  4. 字幕、背景音乐与剪辑合成
  5. 竖屏 3:4 或 9:16 导出
  6. （可选）发布到小红书
- 约束：默认优先免费或有免费额度、国内可用

## 检查点

- 检索覆盖了智能体商店（扣子等）和中文导航站（AI 工具集等）里的“图文成片 / 文字转视频”类工具
- 对比表标出了每个工具缺哪个子功能（常见缺口：小红书风格文案、自动发布）
- 如无完全满足的工具，实施方案把“文案 → 成片 → 发布”拆开组合，并说明自动发布是否可行（小红书开放接口有限，可能需人工发布）
- 所有推荐前 3 的工具国内可用

> 注意：这里只写期望的拆解和检查点，不预设具体工具名。工具结果必须来自实际运行时的检索。
