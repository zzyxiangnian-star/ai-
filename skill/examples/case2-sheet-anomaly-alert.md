# 测试案例 2：表格数据异常监控提醒

**输入：** 我想要一个能自动监控表格数据异常并提醒的智能体。

## 期望的需求拆解（用于检查第 1 步）

- 核心功能：定时检查表格数据，发现异常后自动通知相关人
- 需求类型：自动化与监控（加查 E 集成与接入、D 开源项目）
- 子功能：
  1. 接入表格数据源（飞书多维表格 / 腾讯文档 / 钉钉表格 / Excel）
  2. 定时或数据变更时触发检查
  3. 异常判定（阈值规则，或用大模型识别异常）
  4. 生成异常说明（哪行、哪个字段、偏离多少）
  5. 推送提醒（飞书 / 钉钉 / 企业微信机器人、邮件）
- 约束：默认国内可用；表格是哪个平台不明确时，追问一次或按飞书多维表格处理并写明假设

## 检查点

- 检索覆盖了表格平台自带的自动化 / 提醒功能和扣子等平台的相关插件
- 对比表区分了“表格自带自动化”（通常只支持简单阈值）和“智能异常识别”能力
- 如无完全满足的工具，实施方案给出具体组合，例如：工作流平台定时触发 → 读表格 → 规则或大模型判定 → 机器人 Webhook 通知，并写明每步工作量
- 自研部分写清具体做什么，而不是只写“需要开发”

> 注意：这里只写期望的拆解和检查点，不预设具体工具名。工具结果必须来自实际运行时的检索。
